### PRIS-170 — Data Tasks 可见性控制

**目标**：将任务可见性控制从前端硬编码黑名单（`task_id: '12'`）迁移到数据库字段 + 后端环境判断，实现 beta / prod 独立可见性管理。

#### 后端（`b23c74d`）

- `data_tasks` 表新增两列：`is_visible_beta`、`is_visible_production`
- 新增 `_get_data_tasks_visibility_column()`：根据请求 `Origin` 头判断当前环境
  - `beta-app.prismax.ai` / `localhost:3000` / `127.0.0.1:3000` → `is_visible_beta`
  - 其余（生产） → `is_visible_production`
- 三个接口加入可见性过滤：
  - `GET /data/tasks`：WHERE 条件过滤
  - `GET /data/downloadable-uploads`：JOIN task 时同步过滤
  - `GET /data/qa/uploads`：JOIN `data_tasks` 并加 visibility 条件
- 新增管理接口 `POST /api/vla-admin/tasks/<task_id>/set-visibility`：分别控制 beta/prod 可见性
- `GET /api/vla-admin/tasks` 新增分页：`page` / `page_size` 参数，响应含 `total_pages`

#### 前端（`e5f8349`）

- 删除 `src/utils/taskVisibility.js`（`filterProductionHiddenTasks` / `isTaskHiddenOnProduction`）
- `DataHub`、`DataQAReview`、`UploadDashboard`、`RoboticDataWorkspace` 移除前端过滤调用
- `VLAAdminTasksTable` 重构：
  - 分页：`ITEMS_PER_PAGE = 10`，`currentPage` / `totalPages` state，接口请求带 `page` 参数
  - visibility 列从展示列中隐藏，在编辑/新建表单中以独立 Boolean input 呈现，默认值 `"true"`
  - 列渲染结构化：`LIST_FIELD_COLUMNS`（notes/variations）、`TAG_FIELD_COLUMNS`（objects）、`PROSE_FIELD_COLUMNS`（description）分别以列表/标签/纯文本渲染

**目标**：允许 Amplifier/Innovator 会员提交合作设备上架申请，管理员可查看所有申请记录。

#### 后端（`36db4fe` + `36da4b1`）

### Upload API Key 体系（`cfcc173`）

**目标**：为 Operator 提供专用的程序化 Upload API Key，支持通过 API 创建上传会话和续传，不依赖浏览器 session。

#### 后端（`cfcc173`）

- **新表 `data_api_keys_upload`**：含 `user_id`、`key_prefix`、`key_hash`、`status`、`last_used_at`、`revoked_at`
- **key 格式**：前缀 `pxu_`（区分下载 key `pxa_`）
- **`_require_upload_api_key()`**：从 `X-API-Key` header 提取 → hash 比对 → 验证 `user_role = operator` → 更新 `last_used_at`
- **`_user_owns_machine()`**：校验 machine_id 归属
- **CRUD（Bearer Token 鉴权）**：
  - `GET /data/upload-api-keys`：列出当前 operator 的所有 upload key
  - `POST /data/upload-api-keys`：创建，响应含完整 key（一次性）
  - `DELETE /data/upload-api-keys/<id>`：撤销（status = REVOKED）
- **v1 上传接口（X-API-Key 鉴权）**：
  - `POST /v1/data/upload-sessions`：创建会话，校验 machine 归属、解析文件列表、校验 manifest 完整性，返回 GCS Signed URL
  - `POST /v1/data/upload-sessions/<id>/resume`：续传，跳过已存在且大小匹配的文件，仅为缺失文件生成新 Signed URL
  - `GET /v1/data/uploads/<id>`：查询上传状态及 episode 列表

#### 前端（`df6e36a`）

- **社交账号 UI 重构**：
  - 内联 `TwitterXIcon` / `DiscordIcon` SVG 组件替换原图片
  - 提取通用 `renderSocialAccount` 函数，统一渲染 34×34px icon tile，已连接显示账号名 + Unlink 按钮 + 绿色 badge
- **会员等级展示重构**：
  - `renderCommunityMembershipSection` 三列 tier grid（Explorer / Amplifier / Innovator）
  - `getMembershipTier` / `getMembershipStatus` 计算 current / included / upgrade 状态
  - 显示 "CURRENT" badge、"Included" 标记、升级按钮（带价格）
- **API Keys 管理模块新增**（`renderUploadApiKeysSection`）：
  - Upload / Download 双 Tab，权限分离（upload：仅 operator；download：operator + admin）
  - 创建、复制、撤销全流程 UI
  - 懒加载（首次切入对应 Tab 才请求，`useRef` 防重复）
  - 新建时一次性展示完整 key + 复制按钮

## 六、`task_id` 在 VLA 相关模块中的 API 引用全览

### 6.1 VLA Admin 管理接口（`app_prismax_user_management`）

| API | 方法 | `task_id` 的作用 |
|-----|------|-----------------|
| `/api/vla-admin/tasks` | GET | 返回所有 tasks，`task_id` 为主键，支持分页排序 |
| `/api/vla-admin/tasks` | POST | 新建 task，`task_id` 自动生成或手动指定 |
| `/api/vla-admin/tasks/<task_id>` | PATCH | 按 `task_id` 更新指定 task，`task_id` 不可被修改 |
| `/api/vla-admin/tasks/<task_id>/set-visibility` | POST | 按 `task_id` 单独设置 `is_visible_beta` / `is_visible_production` |
| `/vla/operator-dashboard/uploads` | GET | LEFT JOIN `data_tasks` 关联 `task_id`，返回 `scenario` 字段 |
| `/vla/admin/operator-dashboard/uploads` | GET | 同上，Admin 视角 |

### 6.2 Data Pipeline 接口（`app_prismax_data_pipeline`）

| API | 方法 | `task_id` 的作用 |
|-----|------|-----------------|
| `/data/tasks` | GET | 返回可见 task 列表，按环境过滤（`is_visible_beta` / `is_visible_production`） |
| `/data/tasks/uploadable-task-preview/<task_id>` | GET | 按 `task_id` 查询该 task 下最新一个 DERIVED_READY episode 的预览视频 |
| `/data/upload-sessions` | POST | 请求体必须携带 `task_id`，创建上传会话时写入 `data_uploads.task_id` |
| `/v1/data/upload-sessions` | POST | 同上，API Key 鉴权版本（operator 专用） |
| `/data/upload-sessions/<id>/resume` | POST | 续传时携带 `task_id`，与 DB 中原会话 `task_id` 校验一致性 |
| `/v1/data/upload-sessions/<id>/resume` | POST | 同上，API Key 鉴权版本 |
| `/v1/data/uploads/<upload_id>` | GET | 返回上传记录，含 `task_id` 字段 |
| `/data/uploading-history` | GET | 返回用户上传历史，每条记录含 `task_id`（不做 visibility 过滤） |
| `/data/downloadable-uploads` | GET | JOIN `data_tasks`，按 `task_id` 过滤 visibility，返回可下载 episode |
| `/data/qa/uploads` | GET | JOIN `data_tasks ON task_id`，按 visibility 过滤可 QA 的 uploads |
| `/data/admin/task-json` | POST | 内部聚合接口，通过 `upload_id → task_id` 关联构建 task sample JSON |
| `/data/admin/downloadable-upload-groups` | GET | 按 `task_id` 聚合 upload 分组（Admin 数据导出用） |

### 6.3 引用关系图

```
data_tasks.task_id
    │
    ├── VLA Admin CRUD（查 / 建 / 改 / visibility 设置）
    │       GET  /api/vla-admin/tasks
    │       POST /api/vla-admin/tasks
    │       PATCH /api/vla-admin/tasks/<task_id>
    │       POST /api/vla-admin/tasks/<task_id>/set-visibility
    │
    ├── Upload 写入
    │       POST /data/upload-sessions              ← data_uploads.task_id = data_tasks.task_id
    │       POST /v1/data/upload-sessions           ← API Key 鉴权版本
    │
    └── 读取时 JOIN / 过滤
            ├── /data/tasks                              ← 直接查 data_tasks（含 visibility 过滤）
            ├── /data/tasks/uploadable-task-preview/<id> ← 按 task_id 查预览视频
            ├── /data/downloadable-uploads               ← episodes JOIN tasks（含 visibility 过滤）
            ├── /data/qa/uploads                         ← uploads JOIN tasks（含 visibility 过滤）
            ├── /data/uploading-history                  ← uploads.task_id（不过滤 visibility）
            ├── /vla/operator-dashboard/uploads          ← uploads JOIN tasks（不过滤 visibility）
            ├── /vla/admin/operator-dashboard/uploads    ← 同上，Admin 视角
            └── /data/admin/task-json                    ← 聚合构建 task sample JSON
```

### 6.4 关键结论

| 维度 | 说明 |
|------|------|
| **写入路径** | 仅通过 `/data/upload-sessions`（含 v1）在 `data_uploads` 上记录 `task_id` |
| **带 visibility 过滤** | `/data/tasks`、`/data/downloadable-uploads`、`/data/qa/uploads` 根据请求 `Origin` 动态选列过滤 |
| **不过滤 visibility** | `/data/uploading-history`、`/vla/operator-dashboard/uploads` 直接 JOIN 返回，不受环境可见性限制 |
| **Admin 专属** | `/api/vla-admin/tasks/*` 系列及 `/data/admin/*` 系列通过 JWT 鉴权，Admin 可见全量数据 |
